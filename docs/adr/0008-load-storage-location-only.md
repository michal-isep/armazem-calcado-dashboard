# Only Storage_Location is loaded from the layout files

Six files were supplied besides the order, picking and product files. We load one of them, `Storage_Location.csv` (2,292 locations with x, y, z coordinates), because it describes the warehouse as it is today and lets us place picks in the layout. The other five stay out of the ETL. The four strategy files (Class_Based, Dedicated, Hybrid, Random storage) look like alternative ways of arranging products, so using them would mean comparing scenarios, and the dashboard describes the current state only. `Support_Points_Navigation.csv` is routing data (44 points, ending at `RC-08`); it does not contain the point that matters most, `RC-01`, so it cannot place any more picks. The brief does not say every file must be used. If the teacher says it does, the strategy files are the first to add.
