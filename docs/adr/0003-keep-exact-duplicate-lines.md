# Exact duplicate lines are kept by default

2,559 order lines (about 2.1%) are exact duplicates of another line. Repeated identical single-unit rows are also common in the picking data, so they are probably real repeated lines. We cannot prove either way, so duplicates are kept and a toggle (off by default) shows how much the line-based indicators change if they are removed. Quantity-0 lines are a different case and are excluded.
