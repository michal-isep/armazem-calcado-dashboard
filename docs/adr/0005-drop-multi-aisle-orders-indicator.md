# The multi-aisle orders indicator (A2) is dropped

A2 was meant to replace the multi-sector indicator by counting orders whose picks span more than one aisle. The picking file has no order number, so picks cannot be tied to orders and A2 cannot be computed. A wave-level substitute was rejected because it could be read as an order metric. The multi-sector indicator stays at 0% with a "not informative" badge and has no substitute.
