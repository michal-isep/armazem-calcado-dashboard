# Documentation

Specifications are written before the code. Start with `spec.md`.

| File or folder | Content |
|---|---|
| `user-guide.md` | How to use the dashboard: every page, section, button and filter. |
| `spec.md` | Specification (v2): user, questions, indicators, limitations, data rules, filters, pages, acceptance fixtures. |
| `GLOSSARY.md` | Shared vocabulary. |
| `data-profile.md` | Facts measured on the original CSVs. |
| `adr/` | Decision records 0001 to 0010. |
| `agents/` | How the agent skills use the issue tracker, triage labels and domain docs. |
| `sprint1-summary.md` | Running log: what was done, decided and what is next. |
| `test-plan.md` | Manual test plan and its run. |
| `validation/` | Independent recomputation of every indicator (script and report). |
| `deliverables/` | Repository guide, workflow and speech (PDF). |
